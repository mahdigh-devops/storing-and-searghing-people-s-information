
First, we download and install the postgres program and create a database.
Second, we upload the files to our system.
Third, in the database file, in the database url section, we enter information including the password and database name.
Fourth, we view and download all the libraries from the requirements.txt file.
Fifth, we load the server by entering the uvicorn main:app --reload command in the cmd section.
Sixth, we load the site by double-clicking on the index.html file and use it.
